# cisco-networking-project
Cisco Packet Tracer Networking Project

Overview
This project was designed and simulated using Cisco Packet Tracer to practice fundamental computer networking concepts.

Objectives
Design a network topology connecting multiple network devices.
Configure IP addressing and subnet masks.
Create and Configure VLANs.
Implement inter-VLAN routing.
Configure routing between routers.
Test network connectivity and troubleshoot configuration issues.

Tools used
Cisco Packet Tracer
Kali Linux
GitHub

Networking Concepts
IPv4 addressing and Subnetting
VLAN configuration
Static routing and RIP routing
DHCP configuration, where implemented
Network troubleshooting

Project File
The .pkt file contains the Cisco Packet Tracer network simulation.

Learning Outcomes
This project helped me practice network configuration, routing, IP addressing, and troubleshooting.
